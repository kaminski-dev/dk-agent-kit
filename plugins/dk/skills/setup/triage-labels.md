# Labels

| Role | Label here | Meaning |
|---|---|---|
| category | `bug`, `enhancement` | the kind of change |
| `needs-triage` | `needs-triage` | the maintainer has not evaluated it yet |
| `needs-info` | `needs-info` | waiting on the reporter, usually the customer |
| `ready-for-agent` | `ready-for-agent` | fully specified; an agent brief is posted as a comment |
| `ready-for-human` | `ready-for-human` | needs the maintainer's decision or hands |
| `wontfix` | `wontfix` | declined, with the reason in a comment |
| — | `awaiting-verification` | merged and deployed; only a time-boxed post-deploy check blocks closing |
| — | `spec` | an epic: its sub-issues are the work; never a task itself |
